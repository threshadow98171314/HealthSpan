# HealthSpan

個人健康生涯規劃網站：呈現身體組成、血液與健檢、健身重訓與睡眠數據，附每項數據的 AI 評語、整體評估、建議與規劃。目標是健康、壯碩、健美型身材。

網站：https://threshadow98171314.github.io/HealthSpan/

## 架構

- 這個公開倉庫**只有程式碼，沒有任何健康數據**。
- 數據放在私人倉庫 `HealthSpan-data`，網站登入後透過 GitHub API 讀寫。
- 登入：第一次在裝置上貼上 GitHub 權杖（只限讀寫私人數據倉庫的內容），並設定登入密碼；權杖以密碼加密（PBKDF2 + AES-GCM）後才存在該裝置，之後只要輸入密碼。
- 訓練與睡眠紀錄新增、編輯、刪除後會自動同步；離線時先存在裝置，恢復連線後補傳，並與其他裝置的變更合併。

## 頁面

| 頁面 | 內容 |
| --- | --- |
| 總覽 | 整體評估、三大目標（健康／壯碩／健美）、需要注意的項目、建議、規劃、資料來源與權重 |
| 身體組成 | 趨勢圖、各項指標卡與 AI 評語、部位分析、完整數據表 |
| 血液與健檢 | 依檢驗類別分組，每項含狀態、範圍條、前次比較與 AI 評語 |
| 訓練 | 新增／編輯／刪除訓練紀錄，每週頻率、各肌群組數、主要動作 1RM 進步 |
| 睡眠 | 新增／編輯／刪除睡眠紀錄，每晚時數、作息穩定度 |

狀態色：良好（綠）→ 留意（黃）→ 警戒（橘）→ 不佳（紅）。

## 技術

純靜態網站（HTML / CSS / JavaScript + Chart.js），以 GitHub Pages 發布，無需建置。
